# Global Paralympics Dashboard | Power BI

An interactive Power BI dashboard for exploring Global Paralympics data through visual analytics.

## 📌 Project Overview

The **Global Paralympics Dashboard** is a data visualization project developed as part of a course assignment. It presents Paralympics-related data through an interactive Power BI dashboard, making the information easier to explore and interpret.

The project focuses on dashboard development, visual storytelling, and presenting data in a clear and organized format.

## 🎯 Project Objectives

- Explore Paralympics data through visualizations.
- Present information in a clear and structured dashboard.
- Support data exploration through interactive report features.
- Apply Power BI data visualization concepts in a practical project.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **CSV** — Source dataset format

## 📁 Project File

- `Global-Paralympics.pbix` — Interactive Power BI dashboard.

## 📂 Dataset Information

The dataset was provided in pre-cleaned form as part of a course assignment. Data cleaning was not the primary focus of this project.

The CSV dataset is not included in this repository.

## 🚀 How to View the Dashboard

1. Download `Global_Paralympics_Dashboard.pbix` from this repository.
2. Open the file in Microsoft Power BI Desktop.
3. Explore the available report pages, visualizations, and interactive filters.

## 💡 Key Learnings

- Developing interactive dashboards using Power BI.
- Applying data visualization principles to present information.
- Organizing data into a clear and accessible visual report.
- Communicating information through dashboard design.
